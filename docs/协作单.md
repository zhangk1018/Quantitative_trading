# 协作单

> 方舟与量量之间的工单系统，基于增强黑板模式。
> 最后更新：2026-07-28

***

## 工作流

### 状态机

```
NEW（方舟/量量提单）
  │
  ▼
ASSIGNED（量量/方舟 认领并开始处理）
  │
  ▼
VERIFY（处理完成，待对方验证）
  │
  ├─ ✅ → CLOSED（验证通过，关闭）
  │
  └─ ❌ → REOPENED（验证不通过 → 回到 ASSIGNED）
```

### 各角色职责

| 角色     | 在工单中的职责                                                 |
| ------ | ------------------------------------------------------- |
| **方舟** | 发现前端/后端问题 → 提单（NEW）；量量修复后做前端侧验证（VERIFY→CLOSED/REOPENED） |
| **量量** | 修复后端/数据问题（ASSIGNED→VERIFY）；方舟提的后端问题，量量认领修复              |
| **K**  | 仲裁争议（REOPENED 后双方无法达成一致时）；最终验收                          |

### 生命周期规则

1. **提单方**（通常是发现方）写入工单时状态为 `NEW`
2. **处理方**认领后改为 `ASSIGNED`，开始修复
3. **处理方**完成修复并验证后改为 `VERIFY`，**同时**在 topics.md 追加一行通知对方
4. **验证方**从前端/使用侧验证后：

   - 验证通过 → `CLOSED`

   - 验证不通过 → `REOPENED`，注明原因，**同时**在 topics.md 追加一行通知处理方
5. 一个工单最多 REOPENED 2 次，第 3 次需要 K 介入仲裁

## \[26.0-PDCA-CYCLE-TERMINAL-STATUS-20260828] PDCA 周期状态机缺陷：ACT→PLAN 旧周期未进入终态（请量量处理）

| 字段       | 内容                          |
| -------- | --------------------------- |
| **状态**   | **CLOSED**                  |
| **提单方**  | 方舟                          |
| **日期**   | 2026-08-28                  |
| **影响范围** | backend（pdca/cycles.py 状态机） |
| **优先级**  | P1                          |

**背景**：演示 2026-08W4 周期完整流转（DO→CHECK→ACT→开始新周期）时发现，用户最初问题「执行中何时变『已完成』」暴露系统**缺少周期终态**。

**问题**：[cycles.py](backend/core/api/router/pdca/cycles.py) 状态机 `VALID_TRANSITIONS` 定义 `"ACT": "PLAN"`（L47），`transition_cycle` 主逻辑将**当前（旧）周期** status 直接 `UPDATE` 为目标状态 `PLAN`（L444），同时 `_check_act_to_plan`（L120-179）又 INSERT 新周期（status=PLAN，prev\_cycle\_id 指向旧周期）。结果：**旧周期从「改进中」被重置为「计划中」，而非进入终态**，周期列表出现两个「计划中」周期，历史周期与当前周期无法区分。

**实证**（DB 查询 pdca.pdca\_cycle）：

```
id=1  2026-08W4       status=PLAN  (应为终态「已完成」，现被重置为 PLAN)
id=6  2026-08W4-续    status=PLAN  (新周期，prev_cycle_id=1)
```

浏览器演示复现：点击「开始新周期」后旧周期状态由「改进中」变为「计划中」。

**预期**：ACT 结束时应引入终态（如 `DONE`/`COMPLETED`「已完成」），`transition_cycle` 对旧周期更新为终态、仅新周期为 PLAN；或至少在 ACT→PLAN 分支对旧周期单独置终态，避免与新建 PLAN 周期语义冲突。

**附注（次要观察，非阻塞）**：新周期名称自动生成为 `{旧名}-续`（`2026-08W4-续`），非用户惯常期望的周序号（如 `2026-08W5`），若属设计如此可忽略，请量量一并确认。

**① 取消自动续周期，旧周期进入终态「已闭环」（P1）**
