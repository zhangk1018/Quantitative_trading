## 今日完成

### 1. 自选股「添加自选股」支持代码/名称输入，港美股可搜（P1）
- 弹窗输入框升级为 AutoComplete，支持「股票代码或名称」模糊搜索，下拉展示 `名称 (代码)`。
- 修复此前只搜 A 股的问题：新增 `searchStocksAll`（`/stocks/search` 三市场 cn/hk/us 并发合并去重），`useStockSearch` 与弹窗 `resolveCode` 全部改用它。
- 输入名称不选下拉时，按精确名称/唯一候选中转解析到代码；港美股名称（如「腾讯控股」「阿里巴巴」）、美股 ticker（AAPL/MSFT）均可检索。

### 2. 交易室「标的代码」支持港美股 + 修复 `.HK` 名称前缀 bug + 选中只显示代码（P1）
- 定位并修复港美股名称带代码前缀问题：原 `handleStockSelect` 用 `label.replace(/^\d+\s*/,'')`（纯数字假设），港股 `00025.HK` 会残留为 `.HK CHEVALIER INT'L`。
- 统一为共享方法：新增 `stockSearchOptions.ts`（`buildStockOptions` / `pickStockName`，选项自带 `name` 字段，不再从 label 反解），交易计划两处 + 交易记录表单三处统一调用，消除重复实现。
- 交易计划「标的代码」两处 `Select` 加 `optionLabelProp="value"`：下拉仍显示 `代码 名称`，选中后输入框只显示代码（`2331.HK`），A/港/美三市场行为一致。

### 3. K线除权标注缺省展示（P2）
- 双击自选股/选股列表打开 K 线分析弹窗时，缺省带上「除权」标注（除权日淡紫圆点 + 文字），无需勾选筛选条件；条件事件以合并方式追加，保证不覆盖除权标注。

### 4. 前端信号去重与就绪轮询优化（P2）
- 条件检测器段合并：连续上涨仅在满足段首打标、放量突破阈值收紧至 2.0 且连续段仅首次打标、RSI 超卖仅在回升跨 30 打 1 条拐点，缓解信号叠加。
- `CustomIndicatorService` 对 `/api/snapshot` 就绪 503 做轮询重试（配合后端 33.2 修复）。
