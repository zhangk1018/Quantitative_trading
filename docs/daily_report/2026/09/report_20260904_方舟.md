### 2. M6 前端 T5：K线详情带 market 传参 + 币种展示（P1）

- `StockAnalysisModal.tsx`：优先按 `stock.market`、否则按代码推断市场（`.HK`→hk、字母开头→us、其余 cn），K线请求带对应 `market`，价格按币种（USD/HKD/CNY）格式化展示。

### 3. M6 前端 T6：回测 dataLoader 市场适配 + fx 汇率折算结算（P1）

- **市场适配**（`dataLoader.ts`）：新增 `inferBacktestMarket`（基准推断，恒生/`.HK` 特判 hk，cn 默认不显式传 market）；粗筛/全量请求 `/api/snapshot/all` 按市场带 `market`。
- **fx 汇率折算**（对应协作单 §M4.5 前端结算）：新增 `buildFxRateMap`，按市场取 `HKDCNY=X`/`USDCNY=X`；后端 `/api/fx/rate` 仅支持**单日期 AS-OF**，故按**每月首个交易日为锚点拉取 + forward-fill**（cn 返回 undefined）。
- `engine.ts` 估值循环：`marketValueFen` 按当日汇率折 CNY 统一净值结算；cn 无 map 则 `rate=1`，**A股零回归**。
- `StrategyBacktestView.tsx`：运行引擎前置取汇率表，作为 `fxRateByDate` 传入 worker。
