- **完成**：将策略回测的真·分层止盈状态机移植进回测分析引擎 `backtestEngine.ts`：
  - `SellStrategy` 新增 `layered_take_profit`，`LayeredTPParams` + `DEFAULT_LAYERED_TP_PARAMS`（14 参数），`Trade` 新增 `groupId`
