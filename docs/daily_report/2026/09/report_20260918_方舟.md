### 2. 分层止盈缺陷修复：底仓死扛 + 当日分段卖出冲突（P0）
- **根因（用真实 000798 行情复现）**：TP1 后底仓长期横盘既不涨到 TP2 也不跌破成本时，原 `tp1_done` 阶段无主动离场保护 → 底仓死扛到期末强制清仓（315 天锁仓）；且同日 TP1+保护止损推入超量股数致 `phase=closed` 但股数遗留。
- **修复**：统一 `pushSell` 入账（按当日剩余可卖裁剪）；TP1 后底仓加**峰值回撤追踪 + 均线兜底**主动离场；TP2 卖出量改用全程累计已卖（`totalBuyShares - shares`）修正跨 bar 误全卖。

### 3. 分层止盈参数演进为「4-3-3 + 8% 回撤追踪」（P1）

### 4. 废除「买入失效止损(不涨即走)」（P1）
