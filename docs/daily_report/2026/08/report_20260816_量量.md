方舟违规创建/修改了 `plans.py`、`securities.py`、`snapshots.py`、`__init__.py` 四个后台文件，经三轮审阅修复共 12 项问题：

**第一轮修复（dacf28b）— 竞态条件、性能、安全**
- `create_snapshot`: 改用 `INSERT ON CONFLICT` 替代 check-then-insert 消除竞态
- `create_snapshot`: 捕获 `psycopg2.Error` 替代裸 `Exception`
- `update_snapshot`: 仅资产/出入金字段变更时置 NULL adjusted_nav
- `get_auto_equity_curve`: 用 sweep-line 算法替代 O(n²) 嵌套循环（O(T+D)）
- `get_auto_equity_curve`: 缺失行情数据时记录警告日志
- `list_plans`: 用 `LEFT JOIN` 替代 N+1 循环查询
- `create_plan`: 补全显式 `conn.commit()`
- `update_plan`: 用 `is not None` 替代 `or` 避免吞掉 0 等假值
- `create_security`: 改用 `INSERT ON CONFLICT` 替代 check-then-act 消除竞态

**第二轮修复（8dd2069）— deleted_at 过滤、输入校验**
- `_get_cycle`: 查询增加 `deleted_at IS NULL` 过滤

- `PlanCreate/PlanUpdate`: `max_risk_rate` 增加 `le=1.0` 上限 + `gt=0` 正数校验
- `PlanCreate/PlanUpdate`: `entry_price/stop_loss_price/plan_quantity` 增加 `gt=0` 正数校验
- `get_equity_curve`: 逐条 UPDATE 改为 `executemany` 批量回写
