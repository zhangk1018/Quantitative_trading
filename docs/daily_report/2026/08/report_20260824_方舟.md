### 2. 修复交易计划周期下拉不刷新 Bug（P1）
- 现象：在「周期总览」新建周期后，交易计划页签下拉菜单找不到新周期
- 根因：`TradingPlanEditor` 拉取周期列表的 `loadMeta` 仅在组件首次挂载时执行一次，而 antd Tabs 对已激活页签保持挂载（keepalive），切走再切回不重新挂载
- 修复：
  - `PDCADashboard.tsx`：新增 `planRefreshKey`，每次切到「交易计划」页签时递增并传入
  - `TradingPlanEditor.tsx`：`loadMeta` 的 `useEffect` 依赖 `refreshKey`，页签切回自动重拉周期；「刷新」按钮同时刷新周期下拉 + 计划列表
- 验证：`npx tsc --noEmit` 通过；浏览器实测新建周期后不刷新页面直接切回交易计划，下拉自动出现新周期
