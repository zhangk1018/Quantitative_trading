### 2. Bug 修复：选股结果列表展示不全
- **问题**：量化回测系统选股视图，标题显示"共12只"，但表格仅展示序号7~12，序号1~6不可见
- **根因**：
  - `handleStartScreening` 选股完成后未滚动到表格顶部，虚拟滚动停留在旧位置
  - `fetchFirstPage` 在使用自编指标时返回 stale 闭包中的 `items`/`total`，而非 `runFullScreening` 刚更新的最新值
- **修复**：
  - `useStockPickerActions.ts`：`handleStartScreening` 选股成功后调用 `scrollTo({ top: 0 })`
  - `useScreenerData.ts`：`runFullScreening` 返回实际结果 `{ items, total }`，`fetchFirstPage` 使用返回值替代闭包

### 3. 自选股页签优化
- **问题1**：分组切换（如"全部"↔"沪深"）时表头刷新不完整
  - **修复**：`WatchlistTable` 添加 `key={activeGroup || '__default__'}`，强制切换分组时重新挂载
- **问题2**：操作列仅支持单只删除，需多选/全部删除功能
  - **修复**：
    - `store.tsx`：新增 `BATCH_REMOVE` action、reducer 逻辑、`removeMany` 方法
    - `WatchlistTable.tsx`：新增复选框列、全选/取消全选、批量操作栏（"删除选中"按钮）
    - `index.tsx`：新增 `handleDeleteMany` 回调

### 4. 选股导出格式扩展
- **变更**：导出结果按钮改为下拉菜单，支持 CSV 和 TXT 两种格式
- **新增**：`screener.ts` 中 `exportToTxt` 函数（制表符分隔）
- **修改**：`useStockPickerActions.handleExport` 接受 `format` 参数；`StockPickerBottomBar` 改用 `Dropdown` 组件
