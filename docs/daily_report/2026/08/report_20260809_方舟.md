# 方舟日报 2026-08-09

## 一、今日完成

### 1. K线图左对齐 + 右侧预留3根空位
- **需求**：K线靠左侧展示，数据足量时右侧预留3根K线空位，不紧靠右侧
- **方案**：`rightOffset: 3` + `barSpacing: 6` + `scrollToPosition(0, false)`
- **关键问题**：`autoSize: true` 的内部 ResizeObserver 在 `scrollToPosition` 之后触发，重置滚动位置导致左对齐失效
- **修复**：移除 `autoSize`，改为手动 `ResizeObserver` + `requestAnimationFrame` 中执行 `scrollToPosition`，确保图表布局完成后再滚动

### 2. K线图 setData 断言错误修复
- **问题**：双击"N展芯股份301707"等次新股时，弹窗显示"K线图表加载失败 服务器繁忙，请稍后重试"
- **根因**：Lightweight Charts 的 `setData` 内部断言验证数据严格按时间升序且无重复时间戳，次新股数据量极少时因排序/去重问题触发断言错误，导致图表半初始化（仅显示2根K线或空白）
- **修复**：
  - `candle.setData()` 前增加排序（处理 string/number 混合类型）和相邻去重
  - 所有 `setData` 调用用 `try-catch` 包裹，防止断言错误破坏图表初始化流程
  - `chart-adapter.ts` 中增加数据为空时的提前返回

### 3. 代码审核
