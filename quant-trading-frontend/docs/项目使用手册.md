## 1. 系统概述

### 1.1 什么是 QuantPro

QuantPro 是一套面向个人量化投资者的全栈量化交易系统。前端提供股票筛选、技术分析、回测验证、策略管理等一站式工具，配合后端数据管道，形成完整的"数据采集 → 指标计算 → 选股筛选 → 策略回测 → 结果展示"闭环。

### 1.2 核心功能一览

| 功能模块 | 页签 | 说明 |
|----------|------|------|
| 选股视图 | 选股视图 | 多级筛选股票，支持技术形态、K 线形态、自编指标 |
| 自选股管理 | 自选股 | 分组管理关注的股票，实时行情查看 |
| 回测分析 | 回测分析 | 单只股票策略回测，验证自编指标有效性 |
| 策略回测 | 策略回测 | 组合策略回测，多只股票调仓模拟 |
| 系统配置 | 系统配置 | 全局参数设置、自编指标管理、颜色方案 |

### 1.3 系统要求

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 最新版（推荐）、Edge、Firefox |
| 屏幕分辨率 | 1920×1080 及以上 |
| 后端服务 | 需同时启动 Python 后端（Port 8000） |

## 3. 选股视图

选股视图是系统的核心入口，支持多级条件筛选股票。

### 3.1 界面布局

- **左侧**：条件构建器面板（可折叠）
- **右侧**：结果表格 + 工具栏 + 底部操作栏

### 3.2 条件构建器

条件构建器位于左侧面板，支持以下筛选维度：

#### 3.2.1 范围筛选（行情指标）

点击"范围筛选"展开，可设置以下条件：

| 指标 | 说明 | 示例 |
|------|------|------|
| 收盘价 | 股票收盘价范围 | 10 ~ 50 元 |
| 涨跌幅 | 当日涨跌幅范围 | 1% ~ 5% |
| PE（市盈率） | 滚动市盈率范围 | 0 ~ 30 |
| PB（市净率） | 市净率范围 | 0 ~ 5 |
| 换手率 | 当日换手率范围 | 3% ~ 10% |
| 市值 | 总市值范围 | 50亿 ~ 500亿 |
| 成交量 | 成交量范围 | 大于 1000 万股 |

**操作方式**：输入最小值/最大值，留空表示不限制。点击"开始筛选"按钮执行。

#### 3.2.2 市场筛选

选择目标板块：
- 主板
- 创业板
- 科创板
- 北交所

可多选，默认全选。

#### 3.2.3 技术形态筛选

基于系统预计算的技术指标，选择已形成的技术形态：

| 形态 | 说明 |
|------|------|
| MA 多头排列 | MA5 > MA10 > MA20 > MA60，趋势向上 |
| MA 空头排列 | MA5 < MA10 < MA20 < MA60，趋势向下 |
| MACD 金叉 | DIF 上穿 DEA |
| MACD 低位金叉 | DIF 在零轴下方上穿 DEA |
| MACD 死叉 | DIF 下穿 DEA |
| MACD 底背离 | 价格新低但 MACD 未新低 |
| MACD 顶背离 | 价格新高但 MACD 未新高 |
| BOLL 突破上轨 | 收盘价突破布林带上轨 |
| BOLL 突破下轨 | 收盘价跌破布林带下轨 |
| RSI 金叉 | RSI6 上穿 RSI12 |
| RSI 低位金叉 | RSI6 在 30 以下上穿 RSI12 |
| RSI 死叉 | RSI6 下穿 RSI12 |

**操作方式**：勾选需要的形态条件，多个条件之间为"且"关系。

#### 3.2.4 K 线形态筛选

基于 TA-Lib 识别的经典 K 线形态：

| 形态 | 说明 |
|------|------|
| 锤子线 | 下影线较长，实体较小，可能反转上涨 |
| 早晨之星 | 三日反转形态，可能见底 |
| 黄昏之星 | 三日反转形态，可能见顶 |
| 阳包阴 | 多头吞噬，可能反转上涨 |
| 阴包阳 | 空头吞噬，可能反转下跌 |

**操作方式**：勾选需要的形态，形态强度分为 1~3 级（数字越大越强）。

#### 3.2.5 自编指标筛选

使用自定义 Python 脚本进行高级筛选。详见 [第 9 章 自编指标开发](#9-自编指标开发)。

**操作方式**：
1. 展开"自编指标"区域
2. 从下拉列表选择已创建的指标脚本
3. 设置运算符和阈值（如"6重条件买入 > 7"）
4. 点击"开始筛选"

### 3.3 结果表格

筛选完成后，右侧表格展示符合条件的股票，包含以下列：

| 列名 | 说明 |
|------|------|
| 股票代码 | 6 位数字代码 |
| 股票名称 | 中文简称 |
| 收盘价 | 最新收盘价（前复权） |
| 涨跌幅 | 当日涨跌幅百分比 |
| PE | 滚动市盈率 |
| PB | 市净率 |
| 市值 | 总市值（亿元） |
| 换手率 | 当日换手率 |
| 成交量 | 成交量（股） |

**交互操作**：
- **排序**：点击列头按该列排序（升序/降序切换）
- **多选**：勾选复选框选择股票，支持全选/反选
- **双击**：双击某行弹出 K 线分析弹窗
- **滚动加载**：向下滚动自动加载更多数据

### 3.4 策略管理

#### 保存策略

点击工具栏"保存策略"按钮，输入策略名称，保存当前筛选条件配置。

#### 加载策略

点击工具栏"策略列表"按钮，打开策略抽屉，可选择已保存的策略加载。

#### 导入导出

点击工具栏导入/导出按钮，可将策略导出为 JSON 文件，或从文件导入策略。

#### 策略回测

点击"策略回测"按钮，将当前筛选条件带入策略回测页面，进行组合策略回测。

### 3.5 批量操作

底部操作栏提供：
- **全选/取消全选**：选择当前页所有股票
- **添加到自选股**：将选中股票批量添加到自选股分组
- **导出 CSV**：导出当前筛选结果为 CSV 文件
- **刷新**：重新执行筛选

## 4. 自选股管理

自选股管理页面用于跟踪关注的股票，数据存储在浏览器本地。

### 4.1 分组管理

系统预设分组：
- **沪深**：默认分组，存放主板和创业板股票
- **科创板**：存放科创板股票
- **北交所**：存放北交所股票

**操作**：
- 点击"新建分组"创建自定义分组
- 点击分组标签切换查看不同分组

### 4.2 添加股票

**方式一**：从选股视图批量添加
- 在选股视图中勾选股票 → 点击底部"添加到自选股" → 选择目标分组

**方式二**：搜索添加
- 点击自选股页面"添加"按钮 → 搜索股票代码或名称 → 选择后添加

### 4.3 行情查看

表格展示自选股实时行情，包括：
- 最新价、涨跌幅、PE、PB、市值、成交额、换手率

**交互**：
- 点击列头排序
- 双击某行弹出 K 线分析弹窗
- 悬停显示删除按钮，点击移除股票

### 4.4 数据存储

自选股数据存储在浏览器 localStorage 中，清除浏览器数据会导致自选股列表丢失。建议定期导出备份。

## 6. 回测分析（个股）

回测分析用于验证自编指标在单只股票上的历史表现。

### 6.1 操作流程

1. **选择股票**：输入股票代码或名称搜索
2. **设置日期**：选择回测起始日期和结束日期
3. **选择自编指标**：从下拉列表选择已创建的指标脚本
4. **设置阈值**：配置指标阈值（如"> 0.5"）
5. **点击"开始回测"**：系统加载 K 线数据，在 Web Worker 中异步计算

### 6.2 回测规则

- **买入条件**：自编指标当天为 1（满足条件）则买入
- **卖出条件**：MA5 下穿 MA20（死叉）则卖出
- **仓位管理**：每次买入使用全部可用资金

### 6.3 结果展示

回测完成后展示以下内容：

#### 绩效指标

| 指标 | 说明 |
|------|------|
| 总收益 | 回测期间总收益率 |
| 年化收益 | 折算为年化收益率 |
| 夏普比率 | 风险调整后收益 |
| 最大回撤 | 最大资金回撤幅度 |
| 胜率 | 盈利交易占比 |
| 交易次数 | 总交易次数 |

#### K 线图标注

回测期间的 K 线图上标注买卖点：
- 红色箭头：买入点
- 绿色箭头：卖出点

#### 资金曲线

展示回测期间资金变化曲线。

#### 交易明细

表格展示每笔交易的详细信息：
- 买入日期、买入价格
- 卖出日期、卖出价格
- 持有天数、收益率

#### 诊断报告

展示回测过程中的异常诊断信息，帮助排查问题。

### 6.4 注意事项

- 如果数据库数据无法覆盖选择的起始日期，系统会弹出提示并从最早可用数据开始回测
- 回测计算在浏览器后台线程执行，不会阻塞页面交互
- 回测结果自动保存到浏览器本地存储

## 7. 策略回测（组合）

策略回测模拟多只股票的调仓操作，验证选股策略在历史区间内的组合表现。

### 7.1 操作流程

1. **从选股视图导入条件**：在选股视图中配置筛选条件 → 点击"策略回测"按钮
2. **查看条件摘要**：确认导入的筛选条件
3. **配置回测参数**：
   - 回测区间（起始/结束日期）
   - 资金配置（初始资金、手续费率、滑点、印花税）
   - 调仓频率（每日/每周/每月）
   - 最大持仓数
   - 仓位分配方式（等权重/市值加权）
4. **配置风控参数**（可选）：
   - 止损/止盈比例
   - 单日最大亏损
   - 最大回撤止损
   - 分层止盈（第一锁定→第二锁定→无限续航）
5. **点击"开始回测"**

### 7.2 状态机

策略回测采用状态机管理：
- **Idle**：等待配置
- **Loading**：正在加载数据
- **Running**：回测计算中（可取消）
- **Success**：回测完成
- **Failed**：回测失败

### 7.3 结果展示

#### 绩效指标网格

| 指标 | 说明 |
|------|------|
| 总收益 | 组合总收益率 |
| 年化收益 | 年化收益率 |
| 夏普比率 | 风险调整后收益 |
| Alpha | 超额收益 |
| Beta | 市场敏感度 |
| 卡玛比率 | 年化收益/最大回撤 |
| 信息比率 | 超额收益/跟踪误差 |
| 胜率 | 盈利交易占比 |
| 盈亏比 | 平均盈利/平均亏损 |

#### 图表 Tabs

- **净值曲线**：组合净值变化曲线 + 基准对比
- **持仓明细**：每期持仓的股票列表和权重

## 9. 自编指标开发

自编指标允许用户使用 Python 编写自定义选股逻辑，在浏览器端通过 Pyodide（WebAssembly 版 Python）执行。

### 9.1 快速入门

#### 最简示例：收盘价大于 5 日均线

```python
import numpy as np

def calculate(open_prices, high_prices, low_prices, close_prices, volumes):
    c = np.array(close_prices, dtype=float)
    n = len(c)
    if n < 5:
        return 0
    ma5 = np.mean(c[-5:])
    return 1 if c[-1] > ma5 else 0
```

### 9.2 函数规范

**必须定义 `calculate` 函数**，接收 5 个参数（顺序固定）：

| 参数 | 类型 | 含义 |
|------|------|------|
| 第 1 个 | `list[float]` | 开盘价序列 |
| 第 2 个 | `list[float]` | 最高价序列 |
| 第 3 个 | `list[float]` | 最低价序列 |
| 第 4 个 | `list[float]` | 收盘价序列 |
| 第 5 个 | `list[float]` | 成交量序列 |

**返回值**：
- 返回 `1` 或 `0` 表示是否满足条件
- 返回数值，配合阈值比较（如"指标值 > 30"）
- 返回数组，系统取最后一个有效值

### 9.3 支持的库

仅允许 import 以下模块：
- `numpy`（推荐，性能好）
- `pandas`（可用但不推荐，性能差）

### 9.4 运算符

自编指标筛选支持以下运算符：

| 运算符 | 含义 | 阈值类型 | 示例 |
|--------|------|----------|------|
| `>` | 大于 | 单值 | RSI > 30 |
| `>=` | 大于等于 | 单值 | RSI >= 70 |
| `<` | 小于 | 单值 | RSI < 70 |
| `<=` | 小于等于 | 单值 | RSI <= 30 |
| `==` | 等于 | 单值 | 信号 == 1 |
| `range` | 区间内 | 双值 | 30 <= RSI <= 70 |
| `cross_up` | 上穿 | 双值 | RSI 上穿 30 |
| `cross_down` | 下穿 | 双值 | RSI 下穿 70 |

> 注意：`cross_up` / `cross_down` 需要返回数组序列才能判断，仅返回单值的指标不支持。

### 9.5 校验规则

保存脚本时系统自动校验：

**错误级（不通过）**：
- 公式不能为空
- 公式长度 ≤ 8000 字符
- 括号必须配对
- 不得包含危险关键字（`exec`、`eval`、`os.`、`subprocess` 等）
- 只能 import `numpy` 或 `pandas`
- 必须定义 `calculate` 函数
- `calculate` 必须有 5 个参数

**警告级（提醒但可保存）**：
- 参数名建议包含 open/high/low/close/volume 关键词
- 检测到疑似二维数组用法模式
- 检测到废弃的 `stock_idx` 变量

### 9.6 常见错误

**错误 1：把一维数组当二维数组**

```python
# ❌ 错误：close_prices 是一维数组，close_prices[i] 是第 i 天的价格（单个数字）
def calculate(open_prices, high_prices, low_prices, close_prices, volumes):
    for i in range(len(close_prices)):
        c = np.array(close_prices[i], dtype=float)  # 错误！
```

```python
# ✅ 正确：直接使用整个数组
def calculate(open_prices, high_prices, low_prices, close_prices, volumes):
    c = np.array(close_prices, dtype=float)  # 整个数组 = 这只股票的所有天
```

**错误 2：数据不足未处理**

```python
# ✅ 正确：数据不足时尽早返回
def calculate(open_prices, high_prices, low_prices, close_prices, volumes):
    n = len(close_prices)
    if n < 50:  # 至少需要 50 天数据
        return 0
```

### 9.7 调试技巧

1. 使用 `print()` 输出调试信息，在浏览器 DevTools → Console 查看
2. 先用本地 Python 验证逻辑，再粘贴到前端
3. 从最简版本开始（如 `return 1`），逐步加条件
4. 数据量约 200 个交易日，如需更长周期请做好数据不足处理

|------|------|------|

## 10. 常见问题解答

### Q1：筛选结果为空怎么办？

1. 检查是否设置了过于严格的条件组合
2. 尝试放宽条件范围
3. 确认后端数据是否已更新到最新交易日
4. 检查技术形态和 K 线形态筛选是否与其他条件冲突

### Q2：K 线图显示异常或压缩？

1. 确保浏览器窗口宽度足够（建议 1920px+）
2. 刷新页面重新加载
3. 如果问题持续，可能是浏览器缓存问题，尝试清除缓存

### Q3：自编指标筛选不生效？

1. 打开浏览器 DevTools → Console，查看 Python 报错信息
2. 确认脚本语法正确（可在本地 Python 中测试）
3. 确认 `calculate` 函数有 5 个参数，参数顺序正确
4. 确认返回值类型正确（数值或数组）

### Q4：回测结果与预期不符？

1. 检查回测日期范围是否覆盖足够数据
2. 确认自编指标逻辑正确
3. 查看诊断报告了解异常情况
4. 注意回测中卖出条件固定为 MA5 下穿 MA20

### Q5：策略回测进度卡住不动？

1. 如果数据量较大，预计算自编指标可能需要较长时间
2. 点击"取消"按钮中止当前回测
3. 减少回测日期范围或简化自编指标

### Q6：自选股数据丢失？

自选股数据存储在浏览器 localStorage 中。以下操作会导致数据丢失：
- 清除浏览器数据
- 使用无痕/隐私模式
- 切换浏览器

建议定期使用导出功能备份。

### Q7：页面加载很慢？

首次加载可能需要下载 Pyodide 运行时（约 2.8s），后续访问会使用缓存。如果持续很慢：
1. 检查网络连接
2. 确认后端服务正常运行
3. 清除浏览器缓存后重试

### Q8：涨跌颜色不对？

在"系统配置"页面的"涨跌颜色方案"中切换。中国惯例：红涨绿跌；国际惯例：绿涨红跌。

## 11. 注意事项

### 11.1 数据时效性

- 系统数据每日收盘后通过 ETL 管道更新，非实时数据
- 当日数据通常在 18:30 后可用

### 11.2 浏览器兼容性

- 推荐使用 Chrome 最新版
- 支持 Edge、Firefox 最新版
- 不支持 IE 11 及以下版本
- 需要浏览器支持 WebAssembly（Pyodide 运行时）

### 11.3 性能建议

- 避免同时运行多个回测任务
- 自编指标尽量使用 NumPy 向量化运算，避免 Python for 循环
- 策略回测日期范围建议不超过 5 年
- 自编指标脚本长度不超过 8000 字符

### 11.4 数据安全

- 自选股和策略数据存储在浏览器本地，不会上传到服务器
- 清除浏览器数据会导致本地数据丢失
- 建议定期导出策略和自选股数据备份

### 11.5 已知限制

1. **自编指标**：仅支持 Python 语法，import 白名单限于 numpy/pandas
2. **回测数据**：基本面指标（PE/PB）仅用于初始筛选，回测中无法历史回溯
3. **移动端**：未针对移动端适配，建议桌面端使用
4. **北交所**：部分数据源不支持北交所股票（8 开头代码）
