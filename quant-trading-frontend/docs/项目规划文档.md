## 1. 项目背景

### 1.1 项目概述

QuantPro 是一套面向个人量化投资者的全栈量化交易系统。前端部分（本项目）负责提供股票筛选、技术分析、回测验证、策略管理等功能，与后端 Python 数据管道配合，形成完整的"数据采集 → 指标计算 → 选股筛选 → 策略回测 → 结果展示"闭环。

### 1.2 项目目标

- **核心目标**：为量化投资者提供一站式的选股、分析、回测工具
- **性能目标**：首屏加载 < 3s，选股筛选 < 500ms，回测计算在 Web Worker 中异步执行不阻塞 UI
- **质量目标**：TypeScript 严格模式零错误，单元测试覆盖率 > 80%，E2E 测试覆盖核心流程

### 1.3 项目范围

| 范围 | 说明 |
|------|------|
| 包含 | 选股视图、自选股管理、个股 K 线分析、回测分析（个股）、策略回测（组合）、系统配置 |
| 不包含 | 实盘交易接口、用户认证系统、移动端适配、国际化（i18n） |

## 2. 需求分析

### 2.1 用户角色

| 角色 | 描述 |
|------|------|
| 量化投资者 | 系统唯一用户角色，具备全部功能访问权限 |

### 2.2 功能需求

#### F1 — 选股视图（核心模块）
- **多级筛选**：支持范围筛选（价格/市值/PE/PB/换手率等）、市场筛选（主板/创业板/科创板/北交所）、技术形态筛选（MA 多头排列/MACD 金叉/RSI 金叉/BOLL 突破）、K 线形态筛选（锤子线/早晨之星/阳包阴等）
- **自编指标**：支持用户编写 Python 脚本定义自定义买入条件，通过 Pyodide Worker 在浏览器端执行
- **策略管理**：支持保存/加载选股策略，支持策略导入导出
- **批量操作**：支持全选/反选，批量添加到自选股

#### F2 — 自选股管理
- **分组管理**：支持自定义分组（如"沪深"、"创业板"等），股票跨分组管理
- **实时行情**：展示自选股列表的实时行情数据（价格/涨跌幅/PE/PB/市值等）
- **批量添加**：从选股器批量导入股票到自选股
- **排序与筛选**：支持按各列排序，支持分组筛选

#### F3 — 个股 K 线分析
- **K 线图**：基于 lightweight-charts 的专业级 K 线图，支持缩放、平移
- **技术指标叠加**：MACD、RSI、BOLL、MA、KDJ、ATR 等指标可视化
- **交易信号标注**：K 线图上标注买入/卖出信号点
- **基本面数据**：PE/PB/市值/换手率等基本面指标展示

#### F4 — 回测分析（个股）
- **自编指标回测**：使用自编指标作为买入条件，MA5 下穿 MA20 作为卖出条件
- **Web Worker 异步计算**：回测计算在独立线程中执行，不阻塞 UI
- **结果展示**：绩效指标（总收益/年化收益/夏普比率/最大回撤/胜率）、K 线图标注买卖点、资金曲线、交易明细
- **诊断报告**：回测过程中的异常诊断信息

#### F5 — 策略回测（组合）
- **选股策略驱动**：从选股器导入选股条件作为策略回测的买入条件
- **组合管理**：支持调仓频率设置（每日/每周/每月）、最大持仓数、仓位分配方式
- **风险控制**：止损/止盈、单日最大亏损、最大回撤止损
- **分层止盈**：支持多级止盈策略（第一锁定→第二锁定→无限续航）
- **绩效分析**：总收益/年化收益/夏普比率/Alpha/Beta/卡玛比率/信息比率/胜率/盈亏比等
- **图表展示**：净值曲线、持仓明细、交易日志

#### F6 — 系统配置
- **回测默认设置**：手续费率、滑点、印花税、初始资金等全局默认参数
- **自编指标管理**：创建/编辑/删除自编指标脚本，版本控制
- **涨跌颜色方案**：支持中国惯例（红涨绿跌）和国际惯例（绿涨红跌）

### 2.3 非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 首屏加载 < 3s，选股筛选 < 500ms |
| 可用性 | 支持 Chrome/Edge/Firefox 最新版本 |
| 可维护性 | TypeScript 严格模式，ESLint 零警告 |
| 可测试性 | 单元测试 + 组件测试 + E2E 测试三层覆盖 |
| 安全性 | 错误信息脱敏，不暴露内部实现细节 |

## 3. 技术选型

### 3.1 技术栈总览

| 层级 | 技术 | 版本 | 选型依据 |
|------|------|------|----------|

| 路由 | React Router | 6.23.1 | 声明式路由，支持懒加载和代码分割 |

| 数据校验 | Zod | 4.4.3 | TypeScript 优先的 Schema 校验 |
| 虚拟滚动 | @tanstack/react-virtual | 3.14.5 | 大数据量表格高性能渲染 |
| 测试框架 | Vitest | 2.1.9 | 与 Vite 深度集成，原生 ESM 支持 |
| 组件测试 | @testing-library/react | 16.3.2 | 用户行为驱动测试 |
| E2E 测试 | Playwright | 1.60.0 | 跨浏览器自动化测试，支持 trace/screenshot |
| API Mock | MSW | 2.14.6 | Service Worker 级别拦截，不影响源码 |

### 3.2 技术决策记录

| 决策 | 方案 | 理由 |
|------|------|------|
| 状态管理 | React Context + useReducer | 项目规模适中，无需引入 Redux/Zustand |
| 代码分割 | Vite manualChunks + React.lazy | 按 vendor/antd/charts/monaco 独立分包，首屏仅加载必要代码 |
| 回测计算 | Web Worker | 计算密集型任务不阻塞主线程，保持 UI 响应 |
| 自编指标 | Pyodide Worker | 浏览器端执行 Python，无需后端支持，离线可用 |
| K 线图 | lightweight-charts | 比 ECharts 更轻量，金融图表专用，性能更好 |
| 测试策略 | Vitest + Playwright | 单元/组件/E2E 三层覆盖，Playwright 比 Cypress 更稳定 |

### 4.3 路由设计

| 路径 | 组件 | 页签名称 | 说明 |
|------|------|----------|------|

### 4.4 数据流设计

```
用户操作 → 组件状态 → API 请求 → 后端 FastAPI → PostgreSQL
                ↑                                  ↓
                └──── 响应数据 ←── JSON Response ←──┘

选股流程：
  条件构建 → 后端 SQL 筛选 → 前端自定义指标过滤 → 结果展示

回测流程：
  配置参数 → 拉取 K 线数据 → Web Worker 计算 → 结果渲染
```

### 4.5 性能优化策略

| 策略 | 实现方式 |
|------|----------|
| 代码分割 | Vite `manualChunks` 将 monaco-editor/lightweight-charts/antd/vendor 独立分包 |
| 路由懒加载 | 所有非首屏路由使用 `React.lazy` + `Suspense` |
| 虚拟滚动 | 选股表格使用 `@tanstack/react-virtual` |
| 请求取消 | Axios + AbortController 竞态防护 |
| 缓存复用 | 策略回测数据缓存（基于条件哈希），选股器结果缓存 |
| Worker 卸载 | 回测完成后及时 terminate Worker |

- `TechnicalIndicatorModal` — 技术指标配置

- `StrategyListDrawer` — 策略列表抽屉

**状态管理**：`WatchlistProvider` (React Context + useReducer)，数据持久化到 localStorage

**核心功能**：分组管理、批量添加、删除连锁、排序、实时行情刷新

#### 5.2.3 回测分析 - 个股 (backtest)

**核心组件**：
- `BacktestView` — 主容器（左侧配置 + 右侧结果）

- `BacktestTradeLog` — 交易明细
- `BacktestDiagnostics` — 诊断报告
- `BacktestWarningBar` — 警告提示

**计算引擎**：通过 Web Worker 异步执行，支持取消/重试

#### 5.2.4 策略回测 - 组合 (strategy-backtest)

**核心组件**：
- `StrategyBacktestView` — 主页面（状态机驱动）
- `BacktestPanel` — 参数面板（区间/资金/风控/分层止盈）
- `ConditionsSummary` — 策略条件摘要
- `PerformanceMetrics` — 绩效指标网格
- `ChartTabs` — 图表 Tab（净值曲线/持仓明细/交易日志）
- `EquityChart` — 净值曲线
- `ProgressSection` — 进度条

**状态机**：Idle → Loading → Running → Success/Failed/Cancelling

**计算引擎**：Web Worker 中执行组合回测算法，支持调仓/风控/分层止盈

#### 5.2.5 个股 K 线分析 (stock-detail)

**核心组件**：
- `StockDetailView` — 主页面（K 线图 + 基本面信息）
- `useStockChart` — 图表数据管理 Hook

**数据来源**：后端 API（K 线数据 + 技术指标 + 交易信号）

#### 5.2.6 系统配置 (config)

**核心组件**：
- `ConfigView` — 配置页容器
- `BacktestDefaultsPanel` — 回测默认参数
- `StrategyBacktestDefaultsPanel` — 策略回测默认参数
- `CombinedBacktestPanel` — 综合回测设置
- `CustomIndicatorManager` — 自编指标管理

## 8. 项目风险评估

| 风险 | 等级 | 影响 | 缓解措施 |
|------|------|------|----------|
| Pyodide 初始化慢 | 中 | 自编指标功能首次加载 60s+ | 本地化 Pyodide 文件，预加载优化至 2.8s |
| lightweight-charts 版本兼容 | 低 | K 线图渲染异常 | 锁定版本号，升级前充分测试 |
| 后端 API 不稳定 | 中 | 前端数据显示异常 | 错误状态独立管理，重试机制，友好降级 |
| Monaco Editor 包体积大 | 低 | 首屏加载慢 | 独立分包，按需加载 |
| localStorage 配额超限 | 低 | 策略/设置丢失 | try-catch 保护，友好提示 |
| Web Worker 内存泄漏 | 中 | 长时间使用后页面卡顿 | 及时 terminate Worker，AbortController 取消 |
| 多 Modal 实例冲突 | 已修复 | K 线图压缩显示 | 统一使用 `destroyOnClose` 确保销毁 |

### 10.1 关键技术决策记录

| 编号 | 决策 | 日期 | 理由 |
|------|------|------|------|
| ADR-001 | 使用 lightweight-charts 而非 ECharts | 2026-05 | 金融图表专用，更轻量，性能更好 |
| ADR-002 | 使用 Pyodide 而非后端执行 Python | 2026-06 | 离线可用，减少后端压力，隐私安全 |
| ADR-003 | 使用 React Context 而非 Zustand/Redux | 2026-06 | 项目规模适中，无需额外状态管理库 |
| ADR-004 | 移除 zustand 和 @tanstack/react-query | 2026-07 | 减少依赖，使用原生方案替代 |
| ADR-005 | Vite manualChunks 代码分割 | 2026-07 | 首屏加载优化，按需加载重型库 |

### 10.2 已知限制

1. **自编指标**：仅支持 Python 语法，且 import 白名单限于 numpy/pandas
2. **回测数据**：基本面指标（PE/PB）仅用于初始筛选，回测中无法历史回溯
3. **浏览器兼容**：不支持 IE 11，需现代浏览器（ES2020+）
4. **移动端**：未针对移动端适配，建议桌面端使用
